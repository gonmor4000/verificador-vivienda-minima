# Verificador de vivienda mínima

Herramienta de estudio que genera y verifica la planta de una vivienda mínima de bajo costo en el Perú: RNE (A.010, A.020, E.070, E.030), VIS, antropometría y lógica del manual de construcción para maestros de obra (albañilería confinada, módulo de 25 cm).

- Introduces el lote (o lo estiras arrastrando la planta), los dormitorios por piso y la estructura; la planta, el 2.º piso, la escalera y los cortes se regeneran solos.
- Pestaña **Cuadro de áreas**: superficies de referencia (económico, estándar, amplio) frente a mínimos funcionales y exigencias del RNE.
- Pestaña **Reglas**: las reglas implícitas que usa el generador.

Herramienta de estudio, no un cálculo estructural.

Ver en línea: abre `index.html` o la página de GitHub Pages del repositorio.
